# docs/ — user documentation

| File | Contents |
|------|----------|
| `USER_DOCS.md` | User guide: installation, the two Python contexts, running a campaign end to end, reproducibility and seeding, and the operational traps worth knowing before a long run. |

The repository `README.md` is the reference material — parameter columns,
environment variables, output columns, worked examples. These two documents
cover what the reference does not: how the stages fit together, and what tends
to go wrong.
