# params/ — RVE input parameter decks

Parameter CSVs consumed by `SpaX_Standalone.py` — **one row per RVE**. Columns
are read by name; see the root `README.md` for the authoritative column
reference. These are the *inputs* to the pipeline (the solved outputs live in
`../results/`).

Generated by the scripts in `../studies/`. The decks are grouped by study, e.g.:

| Deck(s) | Study |
|---------|-------|
| `parametric_sea_ice_standalone.csv` | Main depth-graded column sweep. |
| `rve_coltensor.csv`, `rve_basetensor.csv` | Full 6×6 stiffness-tensor slices. |
| `rve_percolation.csv` | Brine-fraction / channel percolation sweep. |
| `rve_morphology.csv`, `rve_orient.csv` | Pocket sphericity and orientation. |
| `rve_channel.csv`, `rve_sizechan.csv` | Channel geometry / RVE-size convergence. |
| `rve_gas.csv` | Gas-porosity sweep. |
| `rve_brineKconst.csv`, `rve_brineKtemp.csv` | Brine `K(T)` study [#5]. |
| `rve_nlgeom_{lin,ten,cmp}.csv` | Large-deformation study [#8]. |
| `rve_tilt00.csv`, `rve_tilt15.csv`, `rve_tilt30.csv` | Channel-tilt study [#6]. |
| `rve_salfamily.csv`, `rve_seasonal.csv`, `rve_seaice_2nd.csv`, … | Salinity-profile family, seasonal warming, second-order, and other sweeps. |

**Usage:** `python3 ../SpaX_Standalone.py params/<deck>.csv out/`
